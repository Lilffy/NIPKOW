### 严禁事项

| # | 禁令 |

## 4. 固件现状

| 模块 | 状态 |
|---|---|
| 时钟 | 168MHz（HSE 8M，PLLM=8/N=336/P=2）✅ |
| 串口 USART2 | 115200 8N1，**发送正常**（banner、SYSCLK）；**接收曾不通**（发 HELP 无反应，未最终确认） |
| 红外 | ✅ 下降沿触发 + 20ms 消抖，`PB2` LED 亮 1 秒（M1 通过） |
| RGB | 共阴 + **S8550 PNP 高边**：`rgb.c` 必须 `CCR = 1000 - 亮度`，TIM3 GPIO 必须 **`GPIO_MODE_AF_OD`（开漏）** |
| 按键 | KEY1=PE11、KEY2=PB12，EXTI 下降沿 + 消抖；按下打印 `[CONTROL] target=... level=...` |
| 电机 | TIM4 CH1 = PB6；当前 PSC=167/ARR=999 → **约 500Hz**（有啸叫可改 PSC=83/ARR=49 → 20kHz） |

### 固件已修复的两个坑（2026-11-16）

1. `Core/Src/rgb.c`：原来写成"高电平点亮"（`CCR = 亮度`）→ 上电 `level=0` 时引脚低 → PNP 全开 → RGB 全亮。**已改为取反。**
2. `Core/Src/stm32f4xx_hal_msp.c`：TIM3 三路 `GPIO_MODE_AF_PP` → **`GPIO_MODE_AF_OD`**（推挽高电平只有 3.3V，PNP 发射极 5V，会半开）

## 5. 已查明的重大设计问题（V2 必改）

| # | 问题 | 修复 |
|---|---|---|
| 1 | U1-66 EXT-BAT+ 接 8.6V | 悬空，或接 3V 电池座 + 防倒灌二极管 |
| 2 | 题目要求 3.3V 供单片机；我们由 5V 经核心板自产 3.3V | 若按题目改，U2 需从 SOT-223 换 TO-220 + 散热（0.8W） |
| 3 | J7 在核心板投影内（V1） | 只能焊线或弯针；V2 需移出 |
| 4 | KEY1/KEY2 原设计用 PC0/PC1，疑似烧毁 | 改 PE11/PB12；V2 注意 6 脚开关两组触点要跨组接 |
| 5 | R10/R11 文档曾写反 | 正确：**R10=120Ω（上分压 +5V↔ADJ）、R11=360Ω（下分压 ADJ↔GND）**，ADJ≈3.75V |
