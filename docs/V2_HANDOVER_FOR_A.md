## 3. 操作步骤（嘉立创 EDA 专业版 V4.1.78）

1. **打开工程** → 双击 `Nipkow.eprj3`
2. **改布局**：按第 2 节的 8 条挪动器件（先挪连接器，再挪被动件）
3. **删掉旧走线**：全选走线 → 删除（或 `布线 → 清除全部布线`）
4. **自动布线**：菜单 `布线 → 自动布线`，范围选"全部网络"，层选 **Top + Bottom**
   - 若自动布线有未完成网络：把该网络先手动连掉，或调小线宽/间距重跑
5. **铺铜**：`铺铜 → 重建全部铜皮`（快捷键 `Shift+B`），确认 GND 全部连通
6. **DRC**：`设计 → 检查 DRC`，**必须 0 error**（连接错误=未布线，间距错误=短路风险）
7. **丝印检查**：位号不压焊盘、不重叠
8. **导出**：
   - `文件 → 导出 → Gerber`（打包 zip）
   - `文件 → 导出 → BOM`
   - `文件 → 导出 → 坐标文件（PickAndPlace）`
   - `文件 → 导出 → PDF`（装配图，可选）
9. **发回**：Gerber.zip + BOM.csv + PickAndPlace.csv +（改动后的）工程 zip
