# 焊接步骤（最终版 · 2026-11-06）

> 适用：手上任意一版板子（V1 或重打的 V2）。按这个顺序焊，每步都有验收。
> 焊前必读：`docs/PITFALLS_AND_FIXES.md`（已知坑）与本文件第 0 节。

---

## 0. 焊前 10 分钟自检

| 检查 | 判据 | 怎么办 |
|---|---|---|
| 板子层数/尺寸 | 2 层、100×90mm | 不符 = 拿错板 |
| **M3 孔** | 4 个 Ø3.2mm，能插 M3 螺丝 | 孔太小 = 旧版 Gerber，见 §0.1 |
| **排母孔** | 2 组，每组 2×20 = 40 孔，共 80 孔；两组内侧行距 **33.02mm** | 不对 = 装不上核心板 |
| **焊盘表面** | 银白（喷锡） | 肉色/发暗 = OSP 或裸铜，见 §0.2 |
| 焊盘 vs 器件 | TP2 对 TP3 **不短路**；TP1/2/3 对 GND 不短路 | 短路 = 先找原因，别上电 |
| 元件清点 | **360Ω×1、120Ω×3、220Ω×1、S8550×3（PNP，SOT-23）** | 见 §0.3 |

### 0.1 如果 M3 孔偏小
旧版 Gerber 曾把 13 个 GND 通孔孔径缩小 10 倍。若 M3 孔插不进螺丝或排母孔插不进针 → 板子是坏版本，**不要焊**，换板。

### 0.2 如果焊盘是肉色/暗铜色
- 橡皮擦或 800 目砂纸轻擦 → 涂助焊剂 → **先给焊盘搪一层薄锡** → 再正常焊
- 焊接温度 350–380°C，单点不超过 2 秒

### 0.3 三极管必须用 PNP
| 型号 | 类型 | 丝印（常见） | 能不能用 |
|---|---|---|---|
| **S8550** | PNP | 2TY / Y2 | ✅ 要这个 |
| MMBT3906 / 2SA1037 / 2N3906 | PNP | — | ✅ 可替代 |
| S8050 | **NPN** | J3Y | ❌ **装上去不亮** |

## 第 1 遍：电源区贴片（先焊，能马上测 5V）

**顺序**（从板边往里）：

1. **R10 = 360Ω**、**R11 = 120Ω** ← 决定 5V，装反只有 1.67V
2. R16 = 470Ω
3. C1、C3 = 10µF/25V；C5、C7 = 100nF
4. C9 = 10µF/25V、C10 = 10µF/25V（0603，不是 100µF）
5. C2、C6 = 10µF/16V + 100nF（3V3 侧）
6. C4、C8 = 10µF/16V + 100nF（5V 侧）
7. **U2（SOT-223，固定 3.3V）**：pin1(GND) 对齐丝印，**贴反会烧**

**验收**：万用表测 TP1/TP2/TP3 对 GND 仍不短路。此时**不上电**（U3 还没装）。

---

## 第 2 遍：红外区贴片（小件，先焊完免得后面挤）

| 位号 | 值 | 注意 |
|---|---|---|
| R12 | **220Ω**（没有就 200Ω） | 红外发射限流 |
| R13 | 1kΩ（弱光换 2.2k） | 接收灵敏度 |
| R14 | 1kΩ | 指示 LED |
| D2 | 0603 LED | **极性**：阴极朝 IR_INDEX 侧，对照 `hardware/assembly_top.png` |

---

## 第 3 遍：RGB 驱动贴片（关键，先确认灯珠类型）

### 3A. 共阴灯（推荐，现有板配这个）

**贴这些：**

| 位号 | 值 | 说明 |
|---|---|---|
| **Q4、Q5、Q6** | **S8550（PNP）** | SOT-23，pin1=基极，别装反 |
| R3 | 180Ω | 红灯限流 |
| R6、R9 | 120Ω | 绿、蓝限流 |
| R17、R18、R19 | 1kΩ | 基极串阻 |
| R20、R21、R22 | 10kΩ | 基极上拉到 +5V |

**这些不贴（DNP）：**

| 位号 | 说明 |
|---|---|
| Q1、Q2、Q3 | AO3400A，共阳备份，**不贴** |
| R2、R5、R8 | 10kΩ 栅极下拉，**不贴** |
| R23 | 0Ω，**不贴** |

### 3B. 共阳灯（备用方案，需要飞线）

如果只有共阳灯，或 S8550 没买到而有 AO3400A：

| 位号 | 值 | 说明 |
|---|---|---|
| **Q1、Q2、Q3** | **AO3400A（NMOS）** | SOT-23 |
| R2、R5、R8 | 10kΩ | 栅极下拉 |
| R3、R6、R9 | 180/120/120 | 限流不变 |

**不贴：Q4、Q5、Q6**（两套同时贴会 +5V→PNP→MOS→GND 直通短路）

**还要做：**
1. **J3-4 飞线到 +5V_REG**
2. **Q1/Q2/Q3 栅极各飞一根线**到 `R_PWM / G_PWM / B_PWM`（U1 的 7 / 10 / 11 脚，或 TP6 等测试点）
3. 固件改：GPIO 推挽 + `compare = duty`（不反相）

> ⚠️ 共阴/共阳只能选一种，**不能混**。

## 第 4 遍：插件小件

1. **H1/H2 排母**（2×20 ×2 组，共 80 孔）
   - 先焊一个角固定 → 插核心板（或定位针）校准 → 再焊其余
   - 确认两组内侧行距 33.02mm
2. TP1–TP9 测试针（或 1P 排针）
3. KEY1、KEY2 轻触开关（6 脚，方向对丝印）
4. J1 电源端子（大口朝板外）
5. J4、J5（2P 排针，红外对管）
6. J6（5P 排针，电机：1=VIN 2=GND 3=PWM）

**验收**：核心板能顺畅插入与拔出（不歪、不紧）。

---

## 第 5 遍：U3 + 散热片（最后装，注意绝缘）

1. U3 = LM1117T-ADJ（TO-220），pin1=ADJ，按丝印
2. **绝缘垫片**贴金属背板，套绝缘粒
3. 涂导热硅脂，上散热片 + M3 尼龙螺丝
4. **万用表测：散热片 ↔ GND 不通**（背板是 5V 电位，短路会烧）

---

## 第 6 遍：接线（不装连接器，直接焊线）

| 接口 | 焊法 |
|---|---|
| **J7（串口）** | **不装直排针**（会顶核心板）→ 4 根线焊焊盘：1=GND、2=PA2(TX)、3=PA3(RX)、4=不接 |
| **J3（RGB）** | 共阴：灯珠 4 线焊焊盘，**4=GND**；共阳：**4=+5V** |
| 电机 | 红→J6-1(VIN)、黑→J6-2(GND)、蓝→J6-3(PWM) |
| 100µF 电解 | 焊在 J1 两端或 J6 电源端（**注意正负极**） |
| 红外对管 | J4 长脚=阳极；J5 的 C/E 按 `docs/IR_DEVICE_CHECK.md` |

---

## 第 7 遍：上电测试（第一次上电必做）

1. **限流 9V / 200mA** 上电；电流突增立刻断电
2. 测电压：

| 测试点 | 期望 | 异常含义 |
|---|---|---|
| TP1（VIN_PROTECTED） | ≈8.6V | 反接/保险 |
| **TP2（+5V_REG）** | **5.00V ±0.1** | 1.6–1.7V = R10/R11 装反 |
| TP3（+3V3_EXT） | 3.30V ±0.1 | 1.25V = U2 是可调版或装反 |

3. 摸 U3：温的正常（<60°C）
4. 断电 → 插核心板 → 短接 JP1 → 再上电
5. 串口 115200：应打印 `SYSCLK = 168000000 Hz`

---

## 第 8 遍：五个功能验证

| # | 操作 | 期望 |
|---|---|---|
| 1 | 上电 + 串口 | 打印时钟 |
| 2 | 遮/通 J4-J5 光路，测 TP5 | 遮光 ≈3.3V，通光 <0.99V |
| 3 | KEY1 切 R/G/B，KEY2 调档 | 三色分别亮，≥4 档可辨 |
| 4 | 遮光再移开 | LED 亮 1 秒后灭，可重复 |
| 5 | KEY1 切 MOTOR，KEY2 调速 | 电机启停、转速变化 |

## 故障速查

| 现象 | 原因 | 处理 |
|---|---|---|
| 5V 只有 1.67V | R10/R11 装反 | R10=360、R11=120 |
| 3.3V 只有 1.25V | U2 可调版/装反 | 换固定 3.3V，重焊 |
| 上电电流大/发烫 | U2/U3 装反、D1 反 | 断电，测三路对 GND |
| RGB 不亮 | Q4–Q6 没贴/装反、灯珠共阳 | 确认 PNP 方向、J3-4 接法 |
| RGB 只有部分颜色亮 | R3/R6/R9 虚焊 | 补焊 |
| 红外不触发 | 对管反、光路偏 | 手机相机看发射管、测 TP5 |
| 串口无输出 | 没共地、TX/RX 未交叉 | 见 `A_HANDOVER_NOTES.md` §4.5 |

---

## 一句话顺序

**电源贴片（R10=360/R11=120）→ 红外贴片 → RGB 驱动（共阴贴 Q4–Q6，共阳贴 Q1–Q3）→ 排母/端子/按键 → U3+散热片 → 焊线（J7/J3/电机）→ 上电测 5.00V → 五任务验收**
