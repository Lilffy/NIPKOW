## 五、供电网络专项核对（"只有一个 VCC 标签"陷阱）

**结论：我们没有这个问题。** 电源网络是分裂命名的，没有把所有供电并到一个 `VCC`：

| 网络 | 成员 | 电压 |
|---|---|---|
| `VIN_MAIN` | J1.1、D1.A | 9V 输入（防反接前） |
| `VIN_PROTECTED` | D1.K、C1/C3/C5/C7/C9/C10、U2.VIN、U3.VIN、J6.1、U1.66、TP1 | 9V（防反接后） |
| `+5V_REG` | U3.VOUT、C4/C8、R10.2、R12.1、Q4–Q6 发射极、R20–R22、JP1.1、TP2 | 5V |
| `+5V_CORE` | JP1.2、U1.40/80 | 5V（仅 JP1 短接时注入核心板） |
| `+3V3_EXT` | U2.VOUT、C2/C6、R13/R14/R16、R23、TP3 | 3.3V（只供红外/指示） |
| `+3V3_CORE` | U1.38/78、R15.2 | 核心板自身 3.3V（**不并入** +3V3_EXT，只用于上拉 PA4） |
| `UART_VCC` | R23、J7.4 | 预留（R23 默认不贴） |

**U2 / U3 接法（从原理图 PDF 逐引脚目视核对）**：

- **U3（LM1117-ADJ）**：pin3 VIN ← `VIN_PROTECTED`；pin2 VOUT → `+5V_REG`；pin1 ADJ 经 R10/R11 分压 → 5.0V ✅
- **U2（LM1117-3.3，SOT-223）**：pin3 VIN ← `VIN_PROTECTED`；pin1 GND → `GND`；pin2/pin4（tab）VOUT → `+3V3_EXT` ✅

> ⚠️ 注意：脚本从 `.esch2` 反推网表时，U2（旋转 90°）的符号位置拟合有歧义，曾把 U2 误判成"VIN/VOUT 接反"——**已用原理图 PDF 目视核对排除**，实际接线正确。旋转器件核对以 PDF/EDA 显示为准。

**真正会导致"一上电就烧"的两个点**：

1. **U2 贴反**（SOT-223 旋转 180°）：VIN/VOUT 互换，9V 直接灌进 3.3V 轨 → 烧 U2、红外、LED。焊接前确认 pin1（GND）方向与丝印。
2. **JP1 短接 + 同时插 USB 供电**：5V 轨与核心板 USB VBUS 并联，可能倒灌。做法：JP1 短接时只用外部 9V；插 USB 调试时断开 JP1。
