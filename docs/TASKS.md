## 0. 相对 V1.0 的关键变更（先看这个）

| 项 | V1.0 写法 | 现在的事实 |
|---|---|---|
| RGB 驱动 | 三路 MOSFET 低边，J3-4 = `+5V_LED`，共阳 | **改为共阴**：Q4–Q6（S8550 PNP 高边）+ 基极 1k/10k，J3-4 = **GND**；Q1–Q3（AO3400A）标 **DNP 不贴**，R1/R4/R7 已删 |
| 供电 | 3.3V 稳压器给 MCU + 红外；5V 给灯 | **5V 经 JP1 注入核心板 `PIN_IN_+5V`**，核心板自带 LDO 产 3.3V；扩展板 U2 的 3.3V 只供红外/指示，并加 R16 假负载 |
| 电机 | 需确定 ESC + 控制协议 | 实物是 **3720 内置驱动无刷电机**（5 线：红/黑/蓝PWM/绿FG/黄未知），不需要 ESC；PWM=PB6/TIM4_CH1 |
| 串口 | 待补 | **已加 J7（1×4 2.54）**：GND / TX(PA2) / RX(PA3) / 第4脚经 **R23(0Ω,默认不贴)** 预留 +3V3；核心板调试口（USART1）可作备用 |
| 排针编号 | 待核对 | 已核对：**40 = PIN_IN_+5V，38 = +3V3**（原交接文档写反，已纠正）；PA9/PA10 只在调试口、不在 2×20 排针上 |
| PA6/PA7 | 未提 | 与核心板板载 **SPI FLASH 共用**（PA4=CS）；已加 **R15 10kΩ 上拉**把 CS 锁高 |
| BOM | 待生成 | 已生成 `docs/BOM.md` + `BOM_draft.csv`（59 项，含 J7/R23），缺立创编号、C10 封装待定 |
| PCB | 未开始 | 59 个封装已按分区摆放（110×90 假设），**板框/安装孔/布线未做** |
