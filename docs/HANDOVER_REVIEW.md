## 2. 关键核对结果（附证据）

### 2.1 ⚠️ 5V / 3.3V 的排针脚号：交接文档写反了

**交接文档说**：`P1-38 = PIN_IN_+5V`，`P1-40 = +3V3`（P2 同理）。

**我从官方 PDF 第 7 页的矢量线段实测**：

- `y=290.9` 的水平导线接的是 **+3V3** 电源端口，对应排针**第 19 行**（右列为 38 号）；
- `y=298.1` 的水平导线接的是 **PIN_IN_+5V**，对应**第 20 行**（右列为 40 号）；
- 两个编号的文本坐标（37/38 在 y≈287、39/40 在 y≈294）与行位一一对应。

**结论：`40 = PIN_IN_+5V`，`38 = +3V3`（两个排针相同）。**

**交叉验证**：你 EDA 里「立创·梁山派-天空星开发板」符号的引脚定义是
`Pin 38 = +3V3`、`Pin 40 = +5V0`、`Pin 78 = +3V3`、`Pin 80 = +5V0` —— **与官方 PDF 一致，你的符号是对的**。

→ **JP1-2 应接 U1 的 40 号脚（H1 侧；镜像位置是 80 号脚/H2 侧）。**
→ 按交接文档接会把 5V 灌到 3.3V 轨上，核心板直接报废。**这条已在交接文档里标红纠正。**
→ 上电前建议再用万用表确认一次（断电，量排针 40 与 38 对 GND 的通断/电压）。

### 2.2 核心板 5V 与 USB 5V 的关系（交接文档第 3 项待验证）

官方 PDF 第 3 页左上角：`USB_IN_+5V` 与 `PIN_IN_+5V` 之间有一个**无位号的菱形元件**（PDF 里没有位号，不在 BOM 里，疑似跳线/网络短接/理想二极管类），
主回路上 USB-C VBUS → `F1 500mA` → `+5V` → `SCJA1117B` LDO → `+3V3`。

- 若菱形是**短接/0Ω**：两者是同一个网络，**USB 与 JP1 5V 绝对不能同时接**（会向电脑 USB 口倒灌）。
- 若是**二极管**：可以同时存在，取高者供电。

**未测量前，按"不同时接"执行**；一测（断电蜂鸣档量 USB VBUS ↔ 排针 40）即可确定。

### 2.3 🔥 U3（LM1117-ADJ，5V）热耗：新发现，必须核算

改成"5V 注入核心板"后，5V 轨负载变大了：

| 负载 | 估算电流 |
|---|---|
| 核心板（3.3V LDO 输入折算） | 100–200 mA |
| RGB 三路（按 7–20 mA/路） | 20–60 mA |
| 红外发射（5V/200Ω） | 19 mA |
| **合计** | **约 150–280 mA** |

U3 耗散：
- 9V 输入：(9−5) × 0.2 ≈ **0.8 W**
- 12V 输入：(12−5) × 0.2 ≈ **1.4 W**

TO-220 无散热片 θja≈50–65 °C/W → 温升 40–90 °C，夏天/封闭壳内会烫手甚至热保护。

**处理（按优先级）**：
1. 输入用**标称 9V**（别用 12V），并给 U3 加散热片/大面积敷铜；
2. 若实测仍过热，改 buck（MP1584/MP2307 模块）——但组委会发的是 LM1117-ADJ，属于自备件，加分/评分不受影响，需确认允许。

### 2.4 ⚠️ PA6 / PA7 与核心板板载 SPI FLASH 共用：新发现

官方 PDF 第 1 页层次图：`SPI-FLASH` 模块接 **PA4(CS) / PA5(CLK) / PA6(MISO) / PA7(MOSI)**。
你的三路 PWM 用的是 `PA6 (R_PWM)`、`PA7 (G_PWM)`。

- 电气上可行：只要 PA4 保持高（片选无效），flash 的 DO 是高阻；PA7 是 flash 输入，也高阻。
- 风险：**PA4 复位后浮空**，flash 可能被误选中，PA6 上出现 flash 输出 → 与 PWM 冲突。
- 处理（二选一）：
  - a) 扩展板上 **PA4 加 10k 上拉到 +3V3**（强制 CS 无效），保留 PA6/PA7；
  - b) 换 PWM 脚到不冲突的定时器通道（如 TIM3 的 PB4/PB5，或 TIM4 的 PB7/PB8/PB9）。
- 需要你定：**板载 SPI FLASH 这次用不用？** 不用就选 a。

### 2.5 U2（LM1117-3.3）轻载：新发现

U2 现在只供 R13(1k) + R14/D2，负载仅 **0.5–4 mA**，低于 LM1117 典型最小负载（5–10 mA），空载时输出可能偏高（>3.4V）。

- 处理：加 330Ω–1k 假负载（≈3–10 mA），或把红外上拉/指示改由**核心板 3.3V（38/78 脚）**供电，直接去掉 U2。

### 2.6 其它复核

- **RGB 限流**：Vf 红≈2.0V、绿蓝≈3.2V，5V 供电时：
  - 现设计 330Ω（红）≈9mA、270Ω（绿/蓝）≈6.7mA —— **偏暗**，且 8 色里的黄色（红+绿）会更暗；
  - 若灯珠额定 20mA：红 150Ω、绿蓝 100Ω；保守取 180Ω / 120Ω（≈17/15mA）。
  - 注意：AO3400A 的 Rds(on)≈30mΩ，压降可忽略；但长时间满占空比对 8mm 灯珠散热有要求。
- **IR 指示 LED 接法**：D2 阳极经 R14 接 +3V3、阴极接 IR_INDEX —— 当 IR_INDEX 被拉低时点亮，**逻辑正确**；但与上拉并联会多灌 0.5mA，可接受。
- **反灌路径**：只有"扩展板带电、核心板未上电（JP1 拔掉）"时，+3V3_EXT 会经 R13 灌入 PA1（约 3.3mA）。按操作规则（拔 JP1 时不单独给扩展板上电）即可规避，或在 PA1 串 100Ω。
- **ERC**：交接文档的 0 错误 10 警告是在 JP1 改动**之前**跑的，不能沿用；改线后必须重跑。
