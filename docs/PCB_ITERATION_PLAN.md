# PCB 迭代打板计划（V1 → V2）

> 背景：组委会允许多次打板，只要按时提交。策略从“一次定型”改为“**V1 验证 + V2 收敛**”。
> 更新：2026-10-26

## 总策略

```
V1（当前 Gerber，已布通/DRC 0）
  → 下单打样（2 层，3–5 天 + 快递 1–2 天）
  → 到板 48h 内跑完「V1 验证清单」
  → 汇总问题 → V2 修改 → 打 V2
  → V2 做最终提交版（V1 留作备件/机械调试）
```

## V1 定位：电气与接口验证

**V1 必须验证的（决定 V2 改不改）**

| # | 验证项 | 判据 | 若不通过 |
|---|---|---|---|
| 1 | 电源：VIN/5V/3V3 | 5V 4.9–5.1V，3V3 3.2–3.4V | V2 改 U3 散热/换 LDO |
| 2 | RGB 灯珠形态 | 4 线=三合一；共阴=可直接用 | 共阳 → V2 改低边/割铜 |
| 3 | RGB 亮度与色准 | 8 色可辨，单色可常亮 | V2 调 R3/R6/R9 阻值 |
| 4 | 红外对射 | 遮光≈3.3V、通光<0.99V（TP5） | V2 调 R12/R13 或改电路 |
| 5 | 电机接口 | 电机能转、方向正确、PWM 有效 | V2 改 J6 定义/加保护 |
| 6 | 核心板排针 | 插拔顺畅、40/38 脚对 | V2 改排母位置 |
| 7 | 机械孔位 | 与鼓/底座装配得上 | V2 改孔径/位置 |
| 8 | 串口 J7 | PC 能收发 | V2 改线序 |

**V1 已知待改进（直接进 V2 清单）**

- C10：0603 只能贴 10µF；100µF 需外接 → V2 换 6.3mm 贴片电解或换 1210
- U3 散热：TO-220 无散热片空间 → V2 加敷铜/预留散热片位置
- J3：4 针端子若灯珠为共阳 → V2 加跳线/割铜焊盘
- 丝印：接口名/极性/版本号可更清楚
- 测试点：TP1–TP9 位置可再优化到板边
- 机械：M3 孔位按实测底座调整
