# 焊接一页纸（共阴灯 · S8550 · 打印版）

> 本板配置已确定：**灯珠共阴 + S8550（PNP）高边驱动**。共阳方案不用，Q1–Q3 不贴。

## ① 值表（焊前对照）

| 位号 | 值 | 位号 | 值 |
|---|---|---|---|
| **R10** | **360Ω** | **R11** | **120Ω** |
| R3 | 180Ω | R6、R9 | 120Ω |
| R12 | **220Ω** | R13、R14 | 1kΩ |
| R16 | 470Ω | R17–R19 | 1kΩ |
| R20–R22 | 10kΩ | R15 | 10kΩ |
| C1、C3、C10 | **10µF/25V** | C2、C4 | 10µF/16V |
| C5–C9 | 100nF | C6、C8 | 100nF |

**不贴（DNP）：Q1、Q2、Q3、R2、R5、R8、R23**

## ② 焊装顺序（7 步）

| 步 | 焊什么 | 关键点 | 验收 |
|---|---|---|---|
| 1 | **R10=360、R11=120** | 装反 5V 只有 1.67V | — |
| 2 | C1、C3、C5、C7、C9、C10、C2、C4、C6、C8、R16 | 0603 先焊 | 三路对 GND 不短路 |
| 3 | **U2（SOT-223）** | pin1=GND 对齐丝印，**贴反会烧** | — |
| 4 | R12=220、R13=1k、R14=1k、**D2（LED）** | D2 阴极朝 IR_INDEX | 目视 |
| 5 | **Q4/Q5/Q6（S8550）** + R3/R6/R9 + R17–R19 + R20–R22 | PNP，pin1=基极 | 三脚间不短路 |
| 6 | 排母 H1/H2 → TP1–TP9 → KEY1/KEY2 → J1 → J4/J5 → J6 | 排母先焊对角两点校准 | 核心板能顺畅插拔 |
| 7 | **U3（TO-220）+ 绝缘垫片 + 硅脂 + 散热片** | 背板是 5V | **散热片对 GND 不通** |

## ③ 接线（不装直针）

| 接口 | 焊法 |
|---|---|
| **J7 串口** | 4 根线直焊：1=GND、2=PA2(TX)、3=PA3(RX)、4=不接 |
| **J3 RGB** | 灯珠 4 线直焊：1=红、2=绿、3=蓝、**4=GND（共阴）** |
| 电机 | 红→J6-1、黑→J6-2、蓝→J6-3 |
| 100µF 电解 | J1 两端或 J6 电源端，注意正负 |
| 红外对管 | J4 长脚=阳极；J5 C/E 见 `IR_DEVICE_CHECK.md` |

## ④ 上电测试

| 测试点 | 期望 | 异常 |
|---|---|---|
| TP1 | ≈8.6V | 反接/保险 |
| **TP2** | **5.00V ±0.1** | 1.6–1.7V → R10/R11 反了 |
| TP3 | 3.30V ±0.1 | 1.25V → U2 装错 |

上电流程：**限流 9V/200mA → 测三路 → 断电 → 插核心板 → 短接 JP1 → 上电 → 串口看 `SYSCLK = 168000000 Hz`**

## ⑤ 故障速查

| 现象 | 原因 | 处理 |
|---|---|---|
| 5V=1.67V | R10/R11 反 | 换回来 |
| 3.3V=1.25V | U2 可调/反 | 重焊/换件 |
| 上电发烫 | U2/U3 反、D1 反 | 断电查 |
| RGB 不亮 | Q4–Q6 反/虚焊 | 查 PNP 方向 |
| RGB 缺色 | R3/R6/R9 虚焊 | 补焊 |
| 红外不触发 | 对管反/光路偏 | 手机看发射管、测 TP5 |
| 串口无输出 | 没共地、TX/RX 未交叉 | 见 `A_HANDOVER_NOTES.md §4.5` |

**核心顺序：值 → 电源贴片 → U2 → 红外 → RGB 驱动 → 插件 → U3+散热片 → 焊线 → 上电测 5.00V**
