## 分区说明

| 区 | 内容 | 位置（约） |
|---|---|---|
| **RGB 驱动** | J3 接口、Q1–Q3（AO3400A，DNP）+ R2/R3/R5/R6/R8/R9、Q4–Q6（S8550 共阴）+ R17–R22 | 左上 x 100–1030, y 300–850 |
| **电源** | J1、D1(SS34)、U2(3.3V)、U3(5V ADJ)、C1–C8、R10/R11、R16、JP1 | 右上 x 1270–1600, y 410–830 |
| **红外** | J4/J5、R12、R13、R14、D2 | 中部 x 845–925, y 670–850 |
| **按键** | KEY1、KEY2（PC0/PC1） | x 1135–1185, y 820–860 |
| **电机** | J6 5P + TP9 | x 1035–1035, y 870–910 |
| **核心板** | U1（天空星 DIP-80）+ R15（PA4 上拉）+ C9/C10（电机退耦） | 右下 x 900–1815, y 1000–1400 |
| **测试点** | TP1–TP9 竖排在左边缘 | x 78–140, y 1250–1600 |
| **串口** | J7（1×4 2.54 排针）：1=GND、2=UART_TX(PA2)、3=UART_RX(PA3)、4=NC | x 280–320, y 1200 |

## 串口（J7）定义

| 针 | 网络 | 说明 |
|---|---|---|
| 1 | GND | 与 USB-TTL 共地 |
| 2 | UART_TX | PA2（USART2_TX），接 USB-TTL 的 RX |
| 3 | UART_RX | PA3（USART2_RX），接 USB-TTL 的 TX |
| 4 | `UART_VCC` | 经 **R23（0 Ω，默认不贴）** 接 `+3V3_EXT`；需要板子供电时才贴 R23，否则悬空 |

## 备注

- Q1–Q3 为共阳备用方案，**BOM 标 DNP 不贴**；栅极串阻 R1/R4/R7 已删除，栅极仅保留下拉，不会误开。
- 共阴主路径：+5V → Q4/Q5/Q6(PNP) → R3/R6/R9 → J3-x（阳极）→ 公共阴极 J3-4 → GND。
- 固件：PA6/PA7/PB0 开漏输出，PWM 极性取反。
- 仍有 7 段历史遗留短导线（已删除元件留下的残桩），不影响电气，ERC 可能报单网络警告。
