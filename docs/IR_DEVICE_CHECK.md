# 红外对管与电路核对结论（5A2L-10 + DY-PT4133B-A2）

> 用途：A 焊接/装配/调试前必读。核对日期：2026-10-26。B 整理。

## 1. 器件参数（来自规格书）

| | 发射管 **5A2L-10** | 接收管 **DY-PT4133B-A2** |
|---|---|---|
| 类型 | 5mm 红外 LED | 5mm NPN 光电三极管 |
| 波长 | 940 nm | 峰值 940 nm（带宽 840–1100） |
| 视角 | 45°（2θ½） | — |
| 正压降 / 电流 | Vf 1.2–1.4 V @ 20 mA；**IF max 20 mA** | Ic max 20 mA |
| 其他 | 辐射强度 15–22 mW/sr @20mA | Vce(sat) ≤0.4 V @2 mA；Vceo 30 V；暗电流 ≤100 nA；tr/tf 15 µs |
| 引脚间距 | 2.54 mm | 2.54 mm |

## 2. 与原理图核对

### 发射侧（J4）
```
+5V_REG ── R12 200Ω ── J4-1 (A) ── LED ── J4-2 (K) ── GND
```
- 电流：`If = (5.0 − 1.3) / 200 ≈ 18.5 mA`（Vf 1.2–1.4 → 18–19 mA）
- 额定 IF max = 20 mA → **占 90–95%，偏紧**
- R12(0603) 功耗 ≈ 68 mW（额定 100 mW，偏热）
- **建议：R12 焊 220Ω**（≈16.5 mA，功耗 56 mW）。近距离亮度绰绰有余。

### 接收侧（J5）
```
+3V3_EXT ── R13 1kΩ ──┬── IR_INDEX（J5-1 = C）
                      ├── PA1（EXTI1 下降沿）
                      ├── TP5
                      └── D2(指示) ← R14 1kΩ ← +3V3_EXT
J5-2 = E ── GND
```
- 拉到低电平需要光电流 ≈ `(3.3 − 0.4) / 1k = 2.9 mA`
- 规格书 Ic(on) 典型 `2.0 mA @ 1 mW/cm²` → 此时 Vce ≈ 1.3 V，**落在逻辑不确定区**
- 但实际近距离辐照度 10–20 mW/cm²（见 §3），Ic 远大于 2.9 mA → 饱和，Vce ≈ 0.2–0.4 V ✓
- **弱光裕度不足时的备用方案：R13 换 2.2kΩ**（只需 1.3 mA；RC 时间 ~百 ns，远小于 ms 级脉冲）

### 波长与机械
- 发射 940 nm ↔ 接收峰值 940 nm（840–1100）→ **匹配**
- 两者 5mm 本体、2.54 mm 引脚间距 → 直接插 J4/J5 的 2.54 排针（HDR-TH_2P-P2.54）
- 接收管黑色透镜可减少环境光干扰

## 3. 对射距离要求

辐照度 `E ≈ I / d²`（I = 15–22 mW/sr）：
| 距离 | E (mW/cm²) | 判断 |
|---|---|---|
| 1 cm | 15–22 | 强饱和 |
| 2 cm | 3.8–5.5 | 饱和 |
| 3 cm | 1.7–2.4 | 基本饱和 |
| 5 cm | 0.6–0.9 | 接近阈值，不推荐 |

**结论：发射/接收对射距离尽量 ≤ 3 cm**，否则光电流不足、PA1 电平不确定。

## 4. 装配极性（关键）

- 发射管：**长脚 = A（阳极）→ J4-1（方焊盘）**；短脚 = K → J4-2（GND）
- 接收管：**C（集电极）→ J5-1（方焊盘）**；E（发射极）→ J5-2（GND）
- 规格书图：发射管 ①=K、②=A；接收管 ①=C、②=E
- 焊前用万用表复核：发射管二极管档正压降约 1.2 V（红笔接 A）；接收管 C–E 正反向都不通（普通三极管特性）

## 5. 调试步骤（A 用）

1. **单测发射管**：5V + 200Ω 串接，手机摄像头对准（940 nm 在手机屏上呈微弱紫点）
2. **单测接收管**：3.3V → 1k → C，E 接 GND，万用表测 C 对地：遮光 ≈3.3 V、照光 ≤0.5 V
3. **板上验证**：J4/J5 插好后测 **TP5（IR_INDEX）**：遮光 ≈3.3 V、通光 <0.99 V
4. **对准指示**：D2 在通光时亮，可用 D2 亮度找最佳对射位置

## 6. 结论

- **器件与电路适配，无需改板**
- 焊接时 **R12 建议用 220Ω**；若实测弱光不稳，**R13 换 2.2kΩ**
- 机械对射距离 ≤ 3 cm（A 设计支架时注意）
