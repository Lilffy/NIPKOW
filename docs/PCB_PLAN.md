## 2. 建议板框与叠层（暂定，等 M1 修正）

- 尺寸：**100 × 90 mm**（3937 × 3543 mil），R3 圆角 —— 满足**单边 <100 mm** 的下单限制
  > ⚠️ 单位：.epcb2 文件内部是 **mil**，EDA 界面默认 **mm**；请按 mm 输入 100×90。
  > 若把 3937/3543 当 mm 输入 → 3.9 m×3.5 m，必然超标。
  > 若平台要求"严格小于 100"，改用 **99 × 89 mm**（器件已按 100×90 摆放，缩小 1 mm 只需微调边缘）
- 安装孔（mm，孔径 3.2）：(5.08,5.08) (94.92,5.08) (5.08,84.92) (94.92,84.92)
  （对应 mil：(200,200) (3737,200) (200,3343) (3737,3343)）
- 2 层板，1.6 mm，1 oz；顶层走信号+器件，底层整片 GND 铺铜
- 板厚/孔径：M3 孔 3.2 mm，铜柱隔离
- 丝印：每个连接器标网络（`VIN 7.4-12V`、`RGB: R/G/B/K(公共)`、`IR_TX/IR_RX`、`MOTOR`、`5V_CORE` 跳线说明）
- 布线：**先用自动布线**，再手工加宽电源/电机线、补 GND 铺铜、清未布通网络

## 4. 布局分区（建议）

```
┌──────────────────────────────────────────────┐
│  [J1 电源端子]   [D1 SS34]  [C1/C3/C5/C7]    │
│  [U2 3.3V] [U3 5V+散热片] [C2/C4/C6/C8]      │
│                                    [TP1-TP4] │
│        ┌──────────────────────┐              │
│        │   核心板 DIP-80 母座   │   [J3 RGB]   │
│        │  (2 × 2×20 排母)      │   [Q4-Q6]    │
│        └──────────────────────┘   [R3/R6/R9] │
│  [J4 IR_TX] [J5 IR_RX]                       │
│  [KEY1] [KEY2]        [J6 电机]  [JP1 5V注入] │
│  [TP5-TP9 沿板边]                             │
└──────────────────────────────────────────────┘
```

原则：
- 电源区（J1/D1/U2/U3/大电容）集中在一角，远离红外接收
- 电机接口 J6 与电机电源走线短、粗，与信号区分开
- RGB 驱动（Q4–Q6 + R3/R6/R9 + R17–R22）靠近 J3
- 红外接收（J5、R13、D2）远离电机与 5V 功率走线
- 测试点全部放板边，探笔可及
- U3（TO-220）周围留散热片空间，避免与排母/端子干涉

## 5. 设计规则建议（2 层板）

| 项 | 值 |
|---|---|
| 最小线宽 | 信号 10 mil；5V 30 mil；VIN/电机 50–60 mil |
| 最小间距 | 8–10 mil（默认 6 偏小，建议 8） |
| 过孔 | 0.3/0.6 mm（电源用 0.4/0.8 或多个并联） |
| 铺铜 | 底层整片 GND；顶层电源区铺铜 + 过孔缝合 |
| 地 | 功率地与信号地单点汇接（在 J1 附近） |
| 丝印 | 不允许压焊盘 |

## 6. 布线顺序

1. 电源：J1 → D1 → C1/C3/C5/C7 → U2/U3 → C2/C4/C6/C8 → JP1
2. 电机：J6-1 ← VIN_PROTECTED 粗线；J6-3 ← PB6 信号线
3. RGB：Q4–Q6 集电极 → R3/R6/R9 → J3；基极网络短而直
4. 红外：J4/J5 → R12/R13/D2 → PA1
5. 按键、测试点、预留网络
6. DRC → 3D 检查 → Gerber/BOM/坐标文件

## 7. 验收检查清单

- [ ] 板框与安装孔与底座一致
- [ ] 核心板插上后不与其他器件干涉（USB 口、按键可达）
- [ ] U3 散热片不碰排母
- [ ] J3/J6/J4/J5 端子插拔方向朝板外
- [ ] 电源/地线宽满足电流（5V 轨 ≈0.3 A、电机峰值待定）
- [ ] 底层 GND 完整，无割裂
- [ ] DRC 0 错误
- [ ] 丝印与实物线序一致（共阴：J3-4 = GND）
