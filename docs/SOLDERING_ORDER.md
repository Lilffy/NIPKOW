# V1 板焊接顺序（照这个焊，不会错）

> 2026-10-31。**焊前先读 `docs/PITFALLS_AND_FIXES.md`**，两类坑：R10/R11 换值、J7/J3 装配顺序。
> 原则：**先贴片 → 再小插件 → 再大插件 → 最后装散热片和接线**。

---

## 0. 准备（焊前 10 分钟）

| 检查 | 标准 |
|---|---|
| 工具 | 烙铁（350°C）、0.8mm 焊锡、助焊剂、镊子、吸锡带、万用表 |
| 空板 | 与 `hardware/assembly_top.png` 对照，确认没漏孔/断线 |
| 万用表 | 测 TP1/TP2/TP3 对 TP4(GND) **不短路**；**TP2 对 TP3 不能通** |
| 元件清点 | 按 `docs/PARTS_IDEAL_VS_OK.md` 清点，特别确认 **360Ω 一颗、120Ω 至少三颗** |

> ⚠️ **R10 焊 360Ω、R11 焊 120Ω**（丝印/BOM 标的是反的）。这是最重要的一条。

---

## 第 1 遍：电源区贴片

**顺序**（从板边往里）：

1. **R10 = 360Ω**、**R11 = 120Ω**（LM1117 分压，决定 5V）
2. R16 = 470Ω
3. C1、C3 = 10µF/25V；C5、C7 = 100nF
4. C9、C10 = 10µF/25V / 100nF
5. C2、C6 = 10µF/25V；C4、C8 = 10µF/16V + 100nF
   - ⚠️ **C6/C7/C8 紧贴 U3，必须先焊**（U3 装上后就焊不到）
6. **U2（SOT-223）**：确认 pin1(GND) 方向与丝印一致，**贴反会烧**

**焊后检查**：万用表测 TP1/TP2/TP3 对 GND 仍不短路；**先不要上电**（U3 还没装）。

---

## 第 2 遍：RGB 驱动贴片（板子右侧）

1. R3 = 180Ω、R6 = 120Ω、R9 = 120Ω
2. R17、R18、R19 = 1kΩ
3. R20、R21、R22 = 10kΩ
4. **R18/R19/R20 必须现在焊**（J3 装上后会盖住它们的焊盘）
5. Q4、Q5、Q6 = S8550（SOT-23，注意 pin1 方向）

**焊后检查**：目视无连锡；Q4–Q6 三个脚之间不短路。

---

## 第 3 遍：红外区贴片

1. R12 = 220Ω（没有就用 200Ω）
2. R13 = 1kΩ（弱光可换 2.2k）
3. R14 = 1kΩ
4. D2（0603 LED，**注意极性**：阴极朝向 IR_INDEX 一侧）

**焊后检查**：D2 方向对照 `assembly_top.png`。

---

## 第 4 遍：不贴的器件（确认不焊）

| 位号 | 状态 |
|---|---|
| Q1、Q2、Q3 | **不贴**（旧低边方案，DNP） |
| R2、R5、R8 | **不贴** |
| R23 | **不贴**（0Ω，预留） |

---

## 第 5 遍：小插件

1. **H1、H2 两个 2×20 排母**（先焊这个，后续测试核心板要用）
   - 注意方向：与丝印 1 脚对齐，两个排母间距 33.02mm
2. TP1–TP9 测试针（或 1P 排针）
3. KEY1、KEY2 轻触开关
4. J1 电源端子（大口朝板外）
5. J4、J5（2P 排针，红外对管）
6. J6（5P 排针，电机：1=VIN 2=GND 3=PWM）

**焊后检查**：H1/H2 插核心板（先不插）看孔位是否对；J1 端子螺丝能拧动。

---

## 第 6 遍：U3 + 散热片（最后装）

1. 绝缘垫片贴在 U3 金属背板，**确认不碰 GND**
2. 装 U3（TO-220，pin1=ADJ 朝板内，按丝印）
3. 涂导热硅脂，上散热片 + 尼龙 M3 螺丝
4. 万用表测：**散热片 ↔ GND 不通**

> ⚠️ U3 背板是 5V 电位，散热片必须绝缘，否则 5V 短路。

---

## 第 7 遍：接线（不装连接器）

1. **J7（串口）：不装直排针**，把 4 根线直接焊到焊盘
   - 1=GND、2=PA2(TX)、3=PA3(RX)、4=UART_VCC（不接）
2. **J3（RGB）：不装座子**，灯珠 4 根线直接焊焊盘
   - 1=红、2=绿、3=蓝、4=GND（共阴）
   - 如果要装座子：**最后装**，因为会盖住 R18–R20
3. 电机线：红→J6-1、黑→J6-2、蓝→J6-3
4. **100µF/25V 电解**：焊在 J1 两端或 J6 电源端（注意正负极）
5. 红外对管：J4 长脚=阳极、J5 的 C/E 方向按 `IR_DEVICE_CHECK.md`

---

## 上电测试（第一次上电）

1. **限流 9V / 200mA**，电流如果瞬间超 200mA → 立刻断电查短路
2. 测：
   - TP1(VIN_PROTECTED) ≈ **8.6V**
   - TP2(+5V_REG) = **5.00V ±0.1** ← 若 1.6–1.7V，R10/R11 装反
   - TP3(+3V3_EXT) = **3.30V ±0.1**
3. 摸 U3：温的正常（<60°C）
4. 断电，插核心板，JP1 短接，再上电
5. 串口 115200 应打印 `=== NIPKOW M0 ===` + `SYSCLK = 168000000 Hz`
6. 用 ST-Link 下载固件（SWD：GND/SWDIO/SWCLK，板子 9V 供电）

---

## 五个功能验证（对应第一阶段）

| # | 操作 | 期望 |
|---|---|---|
| 1 | 上电 + 串口 | 打印时钟，程序运行 |
| 2 | 挡/移开 J4-J5 光路，测 TP5 | 遮光 ≈3.3V，通光 <0.99V；移开瞬间 PB2 LED 亮 1s |
| 3 | 按 KEY1 选 R/G/B，KEY2 调亮度 | 三色分别常亮，亮度至少 4 档可辨 |
| 4 | 挡住再移开红外 | LED 亮 1 秒后灭，可重复触发 |
| 5 | 按 KEY1 到 MOTOR，KEY2 调速 | 电机启停、转速变化 |

## 常见问题速查

| 现象 | 原因 | 处理 |
|---|---|---|
| 5V 只有 1.67V | R10/R11 装反 | 对调（R10=360、R11=120） |
| 3.3V 只有 1.25V | U2 是可调版或装反 | 换固定 3.3V / 重焊 |
| 上电冒烟/电流大 | U2/U3 装反、D1 反 | 断电，测 TP1/2/3 对 GND |
| 串口无输出 | 没共地、TX/RX 没交叉 | 按 `A_HANDOVER_NOTES.md` §4.5 |
| 红外不触发 | 对管插反、光路没对准 | 手机相机看发射管、测 TP5 |
| RGB 不亮 | Q4–Q6 没焊/装反、灯珠是共阳 | 查 Q4–Q6、确认灯珠共阴 |
