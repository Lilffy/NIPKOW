## 1. 🔴 R10/R11 分压值放反（必须处理）

- **现象**：按原理图 BOM 焊，+5V 轨只有 **1.67V**，核心板起不来
- **原因**：LM1117-ADJ 公式 `Vout = 1.25 × (1 + R10/R11)`，R10=OUT–ADJ、R11=ADJ–GND；BOM 里 R10=120、R11=360 → 1.67V
- **应对**：**焊接时对调**

| 位号 | 焊什么 |
|---|---|
| **R10** | **360Ω** |
| **R11** | **120Ω** |

- **验证**：上电测 TP2(+5V_REG) 对 TP4(GND) = **5.00 ± 0.1V**

---

## 2. 🟠 J7 在核心板投影内（直针会顶）

- **数据**：核心板底面离载板 ≈ 11mm；2.54 直排针高 8.5mm，插杜邦母头后 ≈ 11mm → 顶到
- **应对（二选一）**：
  1. **J7 不装排针，串口线直接焊 4 个焊盘**（推荐，0mm，不额外买件）
  2. 装 **2.54 弯针（90°）**，竖直只剩 2.5–3mm（省 6–8mm）

**J7 焊线定义**：1=GND、2=PA2(TX)、3=PA3(RX)、4=UART_VCC（不接）

---

## 3. 🟠 J3 连接器本体罩住 R18–R20

- **数据**：J3 本体约 10×7mm，中心 (77,46.7)mm；R18/R19/R20 在 (73.4/76.7/80.0, 49.7)mm
- **影响**：J3 装上后这几个 0603 焊盘被盖住，焊不到；不会短路
- **应对**：
  1. **先焊 R18/R19/R20（以及所有贴片），最后装 J3**
  2. 更省事：**J3 座子不焊，RGB 灯珠 4 根线直接焊到 J3 焊盘**（高度 0、不被遮挡）

**J3 定义**：1=红阳极、2=绿阳极、3=蓝阳极、4=GND（共阴）

> ⚠️ 弯针只对 J7 有意义；J3 是 XH 插座，不存在"弯针"改法。

---

## 4. 🟠 C6/C7/C8 紧贴 U3

- **数据**：C6/C7/C8 在 y≈21mm，U3 本体上缘 ≈20.5mm，间隙 **0.05–0.1mm**
- **影响**：不影响焊接，但返修困难；U3 装散热片后更挤
- **应对**：**先焊 C6/C7/C8，再装 U3 和散热片**；不要硬掰

## 5. 🟡 C9 / R15 / R23 在核心板投影内

- **数据**：C9 左缘约 0.5mm 在投影内；核心板底面离载板 ≈11mm，0603 高 ≈0.5mm → **不碰**
- **应对**：**插核心板之前焊好**；插入后不再动这些件
- **规则**：投影区内只允许 ≤1mm 高的贴片；排针/电解/端子/测试针一律不得进

## 6. 🟡 J1–D1 太近

- **数据**：J1 右缘到 D1 左焊盘约 **0.35mm**（丝印框重叠约 1mm）
- **影响**：能焊，但容易连锡；丝印重叠是外观问题
- **应对**：焊 D1 时贴胶带保护；焊完用万用表确认 J1 的 VIN 与 D1 焊盘不短路

## 7. 🟢 丝印问题（不影响功能）

| 问题 | 说明 | 应对 |
|---|---|---|
| 位号印错位置 | U1 偏 **40.7mm**、J3 偏 7.1mm、J6 6.7mm、J1/U3 6.4mm、U2/J7 5.4mm、KEY 4.8mm、D1 3.4mm | 用 `hardware/assembly_top.png` 对照找件，别只看丝印 |
| 丝印框相连/压焊盘 | C1–C5、C6–C8 框之间粘连；压到焊盘边缘 | 工厂会把焊盘上的丝印裁掉；不影响焊接 |
| 3D 视图穿模 | 立创库 3D 模型偏大/偏移 | 忽略，导出 Gerber 为准 |

---

## 8. 必须遵守的电学约束

| 约束 | 原因 |
|---|---|
| **只用 9V 输入，禁止 12V** | U3 热耗 12V 时 1.4W，TO-220 撑不住 |
| **U2 必须是固定 3.3V 型号**（丝印 1117-3.3） | 若是 LM1117-ADJ 可调版 → 只有 1.25V |
| **JP1 短接时不要同时插 USB 供电** | 5V 轨与 USB VBUS 并联可能倒灌 |
| **U3 必须装散热片 + 绝缘垫片** | 背板是 5V 电位，不能碰 GND/外壳 |
| **100µF 电解外接** | 板上 C10 只有 10µF，储能不够 |
| **R12 用 220Ω（没有就用 200Ω）** | 200Ω 时 If≈18.5mA，接近额定 20mA |

## 9. 🔧 焊接顺序（照这个来，避免"焊完发现焊不到"）

**第一遍：全部贴片（SMD）**
1. 电源区：C1–C10、**R10=360**、**R11=120**、R16
2. 核心板附近：R15、R23（R23 不贴）
3. RGB 区：R3、R6、R9、R17–R22、**R18/R19/R20 必焊**（J3 之前）
4. 红外区：R12、R13、R14、D2
5. U2（确认方向）、**先不装 U3**（等散热片）

**第二遍：三极管 / 稳压器**
6. Q4/Q5/Q6（S8550）
7. U2 已焊；**装 U3 + 散热片 + 绝缘垫片 + 硅脂**

**第三遍：插件（THT）**
8. H1/H2 排母（注意方向）
9. J1、J4、J5、J6（5P 排针或直接焊线）
10. **J7：不装直针，焊线**（或装弯针）
11. KEY1/KEY2、TP1–TP9

**第四遍：接口线**
12. J3：不装座子 → RGB 灯珠 4 线焊焊盘；装座子 → 最后装
13. 电机线：红→J6-1、黑→J6-2、蓝→J6-3
14. 100µF 电解焊在 J1 或 J6 电源端

---

## 10. 上电检查

1. **断电**用万用表：TP1/TP2/TP3 对 GND 不通；**TP2 对 TP3 不能通**
2. 限流 9V / 200mA 上电
3. 测：TP1≈8.6V、**TP2=5.00V**、TP3=3.30V
4. 若 TP2=1.67V → R10/R11 装反，返工
5. 断电插核心板、短接 JP1、上电看串口 `SYSCLK = 168000000 Hz`

## 11. 为什么建议不重打

| 理由 | 说明 |
|---|---|
| 时间不够 | 11-06 截止，重打 5–7 天 + 焊接 2 天 + 联调 → 来不及 |
| 铜箔能工作 | 已测的冲突都是"紧"或"被遮挡"，不是短路；靠焊接顺序可解决 |
| 丝印问题 | 外观问题，装配图可代替 |
| 已到手 | 手上的板就是交付基础，V2 只能当备份 |

## 12. 如果以后 V2 重打（仅记录）

- 修正 R10/R11 值为 360/120（已改在原理图里）
- R18–R22 移出 J3 本体范围
- C6/C7/C8 远离 U3
- C9 移出核心板投影
- J7 移出核心板投影
- 修正全部位号丝印位置（偏移 >3mm 的 12 个）
- 电源区整体重排（J1/D1/C1 加间距）
