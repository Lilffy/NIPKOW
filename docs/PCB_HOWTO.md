## 2. 摆器件（最影响成败的一步）

### 2.1 定位规则（记牢这 5 条）

| 规则 | 数值 |
|---|---|
| 器件离板边 | ≥ 1mm |
| 贴片之间 | ≥ 0.5mm（实际留 1mm 更好焊） |
| 插件/连接器 与 贴片 | ≥ 1.5mm（**连接器本体不能压贴片焊盘**） |
| 直插件（排针/端子/电解/按键） | **不得进入核心板投影区**（U1 外框 44.97×69.97mm） |
| 投影区内只允许 | ≤1mm 高的贴片（0603/0805），且必须先焊 |

### 2.2 本项目必改的 5 处

| # | 器件 | 现状 | 改成 |
|---|---|---|---|
| 1 | **J3** | 本体 10.2×7mm 罩住 R18/R19/R20 | 把 J3 往右/下移，本体与最近贴片 ≥1.5mm |
| 2 | **C6/C7/C8** | 离 U3 本体 0.05–0.1mm | 各往远离 U3 方向移 1mm |
| 3 | **C9** | 左缘 0.5mm 进核心板投影 | 往右移 1mm 出投影 |
| 4 | **J7** | 已移到 (36,84)mm，出投影 ✅ | 保持，或焊弯针 |
| 5 | **J1/D1** | 间隙 0.35mm | D1 往右移 1mm 到 ≥1mm |

### 2.3 怎么移动

- 鼠标点中器件 → 按住拖动
- 选中后看底部状态栏的 X/Y 坐标，可精确输入
- 移动后**走线不会自动跟着**，需要重连（第 4 步）
- 移动完看有没有飞线（细线）变多——那是断开的网络

**验收**：所有器件不重叠、不压焊盘、不超板边、核心板投影区无插件。

## 3. 丝印整理（可选但建议）

- **位号文字**（C1、R10…）要贴近器件，不能叠在焊盘上
- 选中文字 → 拖动到器件旁边
- 本项目已知偏移大的：**U1（偏 40mm）、J3（7mm）、J6、J1、U3、U2、J7、KEY**
- 丝印线宽用默认 0.15mm

---

## 4. 布线

### 4.1 规则

| 类型 | 线宽 |
|---|---|
| 电源（VIN / 5V / 3V3） | **30–40 mil** |
| 信号 | 10–12 mil |
| GND | 不布，靠铺铜 |
| 过孔 | 12/24 mil（内径/外径） |
| 间距 | ≥ 6 mil（默认规则） |

### 4.2 顺序（很重要）

1. **先布电源**：VIN_PROTECTED → U2/U3 → +5V_REG / +3V3_EXT
2. **再布关键信号**：RGB 三路 PWM、IR_INDEX、电机 PWM、串口
3. **最后布其余**（按键、指示灯）

### 4.3 两种方式

**方式 A：自动布线（推荐先用）**
- 菜单 `布线 → 自动布线`
- 范围：全部网络；层：Top + Bottom
- 跑完看结果：有时长、成功数
- 跑不动的网络，手动补

**方式 B：手动布线**
- 快捷键：`W` 进入走线模式
- 点一个焊盘 → 拖到另一个焊盘 → 双击结束
- 换层：走线中按 `V` 放一个过孔
- 走线避开焊盘/过孔，保持 ≥6mil 间距

**验收**：所有飞线（细线）消失；DRC 无 Connection Error。

---

## 5. 铺铜（GND）

1. 菜单 `铺铜 → 重建全部铜皮`（或快捷键 **Shift+B**）
2. 检查：GND 网络全部连通（DRC 无 GND 未连接）
3. 铜皮与走线/过孔/焊盘间距要满足规则（DRC 无 Clearance Error）

> 本项目当前的 138 个 DRC 错误全是"旧铜皮 ↔ 新走线"，**重建一次就消失**。

---

## 6. DRC（出板前最后一道关）

1. 菜单 `设计 → 检查 DRC`
2. 目标：**0 error**（Connection Error 和 Clearance Error 都要清）
3. 逐条点错误 → 自动跳转 → 修正
4. 提醒：网表不一致（Netlist Error）→ 点 `设计 → 导入变更` 同步原理图

**验收**：DRC 页面无红叉；统计里 Connection=0、Clearance=0。

## 9. 常见错误（新手最容易犯）

| 错误 | 后果 | 避免 |
|---|---|---|
| 连接器本体压住贴片 | 焊完装不上/焊不到 | 摆件时看本体外框，不看焊盘 |
| 器件进核心板投影 | 顶核心板/焊不到 | 画一个 U1 外框当禁区 |
| 电源线太细 | 压降/发热 | 30–40mil |
| 忘铺铜 | GND 不连续、干扰 | 出板前 Shift+B |
| DRC 有错就导出 | 板子短路/断线 | DRC 必须 0 |
| BOM 值与原理图不一致 | 买错料 | 导出 BOM 后核对 |
| 丝印压焊盘 | 焊接时白字影响 | 丝印避开焊盘 |
