| 器件型号 | RGB 灯珠、电机的具体型号 | ✅ 能 | 只要接口定义不变 |
| 共阳/共阴 & 引脚顺序 | J3 的 4 脚定义 | ✅ 能 | 原理图改网络标签即可；**前提是还没画 PCB** |
| 电机线序 | J6 的 5 脚定义 | ✅ 能 | 同上；连接器封装先按 5P 2.54 定 |
| **MCU 引脚分配** | PA6/PA7/PB0/PB6/PA1/PC0/PC1/PA2/PA3 | ❌ 现在冻结 | 改脚会牵动整张图的网络标签、固件、测试点 |
| **接口清单** | 电源/RGB/IR×2/电机/按键/UART/测试点 | ❌ 现在冻结 | 少一个接口 = 阶段二没法做；打板后加不了 |
| **电源与保护架构** | 5V 注入、防反接、LDO、滤波 | ❌ 现在冻结 | 已确认，改动影响布局与安全 |

## 2. 现在就要补的三项（不改会卡阶段二）

1. **UART 接口**：当前 PA2/PA3 是单点网络、没有连接器 → 加 3 针排针（TX/RX/GND），或明确改用核心板调试口 USART1（PA9/PA10）。**阶段二"PC 实时传图"必须有。**
2. **电机电源储能电容**：J6-1 处加 100 µF/25 V 电解 + 100 nF，抑制启动/换相尖峰（否则电机一启动，5V/3.3V 可能被拉崩、索引误触发）。
3. **PA4 上拉**（若保留 PA6/PA7 做 PWM）：核心板 SPI FLASH 的 CS=PA4 复位后浮空 → 加 10 kΩ 上拉到 +3V3，强制片选无效；否则换 PWM 到 PB4/PB5（TIM3 重映射通道）。

## 7. 盲打 PCB 的兼容设计（2026-10-24 追加）

> 情况：PCB 必须先打，灯珠/电机后到 → 不能先验实物再定电路。
> 原则：**"值"可以后定，"拓扑"必须现在兼容。**

### 7.1 能后定 / 不能后定

| 项目 | 能否靠换元件解决 | 处理 |
|---|---|---|
| 限流电阻值 | ✅ 可以 | 0603 焊盘，装配时按实物 Vf/If 计算后贴装；BOM 标 TBD |
| 电流档位 | ✅ 可以 | 可并两个 0603 位（如 180Ω∥330Ω）留调节余地 |
| 共阳 / 共阴 | ❌ 不能（要换驱动拓扑） | PCB 做**双拓扑兼容**（见 7.2） |
| LED 四脚顺序 | ✅ 可以（灯珠焊线安装） | J3 用可插拔端子/排针，装配时按丝印对应接线 |
| 电机线序 | ✅ 可以 | J6 用可插拔端子；黄线不接 |
| 电机 PWM 电平（3.3/5 V） | ⚠️ 可能需电平转换 | 预留 0Ω 上拉到 5V + 可选反相/缓冲位 |
| C10 电解封装 | ⚠️ 打板时就要定 | 统一按 6.3×7.7 mm 通用封装，容值 100µF/25V |

### 7.2 双拓扑兼容方案（RGB）

```
公共端 J3-4 ──[JP2 焊盘跳线]── +5V_REG（共阳）或 GND（共阴）
每通道 J3-x ── R(限流) ──┬── 0Ω ── NMOS 漏极（源极 GND）      ← 共阳时贴
                        └── 0Ω ── PNP 集电极（发射极 +5V）    ← 共阴时贴
栅极/基极控制：NMOS 100Ω + 10k 下拉；PNP 1k + 10k 上拉到 5V
```

- 增加器件：3× PNP（S8550/2SA1037，SOT-23）+ 6× 0Ω 0603 + 3× 10k + 焊盘跳线 ×4
- 成本增加 < 1 元，板面约 15×10 mm
- BOM 标注：**"按实物选贴"**，默认只贴 NMOS 那组

### 7.3 其他盲打保险

- J3/J6/J4/J5 全用 2.54 排针/可插拔端子，线序靠装配对应，不依赖买的插头
- 每个不确定节点放测试点（PWM、公共端、电机 PWM、FG）
- 丝印标出：`+5V / GND / R / G / B / INDEX / PWM / VIN`
- 板边留 2–3 组备用 0Ω/焊盘跳线位，便于飞线补救

### 7.4 2026-10-24 组委会口径 → 最终决定

**"共阴共阳都行，但推荐共阴"；后续确认：组委会内部测试用的是共阴。**

→ **最终决定：按共阴设计。**

| 项 | 内容 |
|---|---|
| 拓扑 | +5V_REG → PNP(S8550) 高边 → 限流电阻 → J3-x（灯珠阳极）；J3-4 公共阴极 → **GND** |
| PNP 驱动 | 基极经 1 kΩ 到 MCU（PA6/PA7/PB0），基极 10 kΩ 上拉到 +5V_REG；**GPIO 必须配置为开漏输出**（低=亮，高阻=灭） |
| 逻辑 | 与共阳相反：PWM 占空比在固件里取反 |
| 限流 | R3（红）180 Ω ≈15.6 mA；R6/R9（绿蓝）120 Ω ≈13.3 mA（按 Vce≈0.2 V 计） |
| 现有 NMOS | Q1–Q3、R1/R2、R4/R5、R7/R8 保留但**不贴**（BOM 标注）；其漏极到 R3/R6/R9 的连接需断开，避免误开时 PNP 与 NMOS 直通 |
| 需要新增 | ✅ 已完成：Q4–Q6（S8550，SOT-23）、R17–R19（1 kΩ 基极）、R20–R22（10 kΩ 上拉） |

**为什么必须开漏**：PNP 发射极在 5 V，若 GPIO 推挽输出 3.3 V，Vbe≈1.7 V 仍会导通 → 灯关不死；开漏（或高阻）时由 10 kΩ 把基极拉到 5 V 才能关断。
