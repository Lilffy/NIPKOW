# 硬件核查清单（V1 板到货后按顺序执行）

> 2026-10-30 板到货当天用。**先看第 0 节，有两处必须先改，否则上电就出事。**

## 🔴 0. 上电前必须做的两处修正（最重要）

### 0.1 R10 / R11 阻值必须对调（否则 5V 轨只有 1.67V）

LM1117-ADJ 输出公式：`Vout = 1.25 × (1 + R2/R1)`，其中 **R2 = OUT–ADJ（R10）**，**R1 = ADJ–GND（R11）**。

原 BOM/原理图：R10 = **120Ω**、R11 = **360Ω** → `1.25 × (1 + 120/360) = 1.67V` ❌（核心板起不来）

**正确做法（焊之前改）**：
- **R10 位置焊 360Ω**
- **R11 位置焊 120Ω**
- 验证：`1.25 × (1 + 360/120) = 5.00V` ✅

> 手上的料正好够：120Ω 有 3 颗（R6、R9、**R11**），360Ω 有 1 颗（**R10**）——把标签对调着焊即可，不用补买。

### 0.2 U2 方向 + 型号确认

- U2（SOT-223，3.3V LDO）：**pin1 = GND**，焊接前确认 pin1 与丝印/封装缺口方向一致；**贴反 = 9V 灌进 3.3V 轨，烧 U2 + 红外 + LED**
- 确认 U2 是**固定 3.3V 型号**（丝印 `1117-3.3` / `AMS1117 3.3`）。若发到的是 `LM1117-ADJ`（可调版），板上没有分压电阻 → 输出只有 1.25V，必须换料

## 3. 焊接顺序 + 分阶段上电

**阶段 A：只焊电源区**
1. J1、D1、C1/C3/C5/C7、C9/C10（VIN 侧）
2. U3 + C4/C8 + **R10=360Ω / R11=120Ω（注意对调）**
3. U2 + C2/C6 + R16
4. JP1 先**不短接**、U1 排母**先不焊**
5. 限流电源 9V / **200mA**，测：
   - TP1（VIN_PROTECTED）≈ **8.6V**（9 − 0.4 肖特基）
   - TP2（+5V_REG）≈ **5.00V**（±0.1）← **若 1.6–1.7V 说明 R10/R11 装反了**
   - TP3（+3V3_EXT）≈ **3.30V**（±0.1）
6. 摸 U3 温度（正常微温）

**阶段 B：核心板座 + 基本外设**
7. 焊 H1/H2 两个 2×20 排母（注意方向，别焊反）
8. 焊 C9/C10 附近的 R15、J7、R23（R23 不贴）
9. 断电，插核心板，JP1 短接
10. 上电：核心板应亮；测核心板 5V/3.3V；ST-Link 下载固件，串口 115200 应打印 `=== NIPKOW M0 ===`

**阶段 C：驱动与接口**
11. 焊 Q4–Q6 + R3/R6/R9 + R17–R22 + J3（Q1–Q3/R2/R5/R8 **不贴**）
12. 焊 J4、R12（用 220Ω 更好，200Ω 也能用）
13. 焊 J5、R13、R14、D2
14. 焊 KEY1/KEY2、J6、TP1–TP9
15. 全系统上电复测三路电压 + 各功能

## 6. 常见异常对照

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 上电电流大/冒烟 | 电源短路（U2/U3 装反、D1 反） | 立即断电，万用表查 TP1/2/3 对 GND |
| 5V 只有 1.67V | R10/R11 值装反 | 对调（R10=360、R11=120） |
| 3.3V 只有 1.25V | U2 是可调版或装反 | 换固定 3.3V 型号 / 重焊 |
| 核心板不亮 | JP1 未短接、排母虚焊、核心板 5V 输入不足 | 测 +5V_CORE、补焊 |
| 串口无输出 | GND 未共地、TX/RX 未交叉、波特率不对 | 按 `A_HANDOVER_NOTES` §4.5 排查 |
| 红外无反应 | J4/J5 插反、R12/R13 虚焊、光路没对准 | 测 TP5、手机相机看发射管 |
| RGB 不亮/颜色反 | 灯珠共阳、Q4–Q6 虚焊、J3 线序错 | 核对 J3-4=GND（共阴） |
