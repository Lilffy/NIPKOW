### 缺项（必须补）

| 缺什么 | 为什么 | 怎么补 |
|---|---|---|
| **U3 散热片 10×10×8** | TO-220 在 9V/0.8W 下需散热 | 立创/淘宝几块钱 |
| **绝缘垫片 + 绝缘粒** | U3 背板是 5V 电位，散热片不能碰 GND/外壳 | 同上，买 TO-220 绝缘套装 |
| **导热硅脂** | 散热片贴合 | 一小支 |
| **J6 电机连接器（MDF7-5P 母壳/端子 或匹配线束）** | 板上 J6 是 MDF7-5P 针座，电机线需对应母壳 | 确认电机自带线束是否匹配；不匹配就买 MDF7-5P 压接线束或直接焊线 |
| **J3 的 XH2.54 4P 母壳 + 端子（可选）** | J3 是板端针座，若灯珠是裸线 | 要么买 4P XH 母壳压线，要么把线直接焊在 J3 引脚上 |
