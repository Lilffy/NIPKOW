# 原理图看着"粗糙"？——原因和怎么用

> 针对 B 导出的 `hardware/schematic.pdf`（1 页，A0 画布导出）
> 结论先给：**图画得确实糙，但电路是对的**；打板不靠这张图，焊接也不用靠它找位置。

---

## 1. 为什么看着糙（4 个具体原因）

| 现象 | 真正原因 |
|---|---|
| 整页大片空白、器件挤在中间一小块 | 画布是 **A0**（约 795×563 mm），内容只占中间一部分，导出后缩到 A4 就全变小 |
| 位号/参数文字叠在一起 | 例：`C1` 和 `C5` 完全重叠、`C4` 和 `C8` 叠成一团、`R16` 压在 `C8` 上、U3 的 `ADJ` 与参数 `1.25` 打架 —— **文字没有自动避让** |
| 元件之间没有连线，只有一小段短线和名字 | 这是"**网络标签**"画法：同名网络自动相连。看图的人得靠名字找对应，所以显得断成一片 |
| 核心板 U1 是一张**实物照片** | 符号库里选了带 3D 预览的符号，不是标准原理图符号 |

一句话：**电气信息是全的，排版是赶工出来的**。B 自己是写代码的，画图只求"能出网表、能布线"，没花时间做排版。

---

## 2. 但我核对过了：电路本身没问题

对着网表（`docs/NETS.md`）和这张图逐块比对：

| 块 | 图上内容 | 结论 |
|---|---|---|
| 输入保护 | J1 → D1(SS34) → `VIN_PROTECTED` | ✅ 方向对（白条朝板内） |
| 5V | U3(TO-220) + R10=120/R11=360 → 5.0V | ✅ 1.25×(1+360/120)=5.0 |
| 5V 滤波 | C4=10µF + C8=100nF → `+5V_REG` | ✅ |
| 3.3V | U2(LM1117-3.3) + C2=10µF + C6=100nF | ✅ |
| 3.3V 假负载 | R16=470Ω 到 GND（≈7mA） | ✅ 解决轻载不稳 |
| 核心板供电 | JP1：`+5V_REG` → `+5V_CORE` | ✅ 对应 40 脚 |
| 输入电容 | C1/C3=10µF、C5/C7=100nF | ✅ 与网表一致 |

> 唯一要盯的仍是那句：**C1/C3 是 10µF 0603 挂在 9–12V 上**，买的时候选 16V 以上；C10 已改 10µF/25V，100µF 外接。

## 4. 读这种图的三个原则（学会就不难受了）

1. **同名网络就是连在一起的**。看到两根短线头都写着 `VIN_PROTECTED`，它们在电气上是一根线，不用找连线。
2. **短线头 + 名字 = 网络标签**。核心板 80 根脚都是这种画法（`PA6`、`+5V_CORE`…），靠名字对应到别处。
3. **位号是身份，参数是值**。`C4` 是位号（板上丝印会印），`10uF` 是值。文字叠在一起时，以丝印为准——**板子上每个元件旁边都印了位号**。

## 5. 焊接时别用这张图找位置

按这个优先级：

| 用途 | 用什么 |
|---|---|
| 找元件在板上哪儿 | **PCB 丝印**（板上有 `C4` `R3`…）+ `docs/hardware/gerber_preview.png` |
| 判断方向/极性 | 板上的丝印标记（白条、+、圆点） |
| 确认这一块是什么电路 | 本文件的分块图 + `A_HANDOVER_NOTES.md` §5 测试点表 |
| 确认元件值 | `hardware/BOM.csv`（B 导出，最准） |

## 6. 想让 B 重导一版好读的（可选，不影响打板）

跟 B 说这四句就够：

1. 导出 PDF 时选**"按内容范围"**（不要整张 A0 画布），或者把画布缩到 A3；
2. 用**布局 → 属性位置**把位号/参数错开，别叠在一起；
3. 把四个区用**方框 + 文字标题**框起来（电源/RGB/红外/接口），焊接的人一眼能定位；
4. U1 换成**标准符号**（或直接标 80 脚表），别用实物照片。

> 但优先级不高：**板子照样打，焊接照着丝印和 BOM 来**。这张图只是"看懂电路"用的。
