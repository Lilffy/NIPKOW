# 两人分工方案（基于赛题原文 + 核心板原理图）

> 依据：`docs/refs/赛题_2026第四届.pdf`（5 页，第一阶段 5 项 / 第二阶段 8 项 / 加分 a–e / 表 1 主要元器件表）、`docs/refs/天空星核心板原理图.pdf`（第 7 页双路 80pin 排针已核对）
> 适用：2 人、约 4–7 周、两块板（扩展板 + 核心板）
> 结论先给：**按「硬件 / 软件」切主轴，按「任务组」交叉验收**。PCB 是单线程关键路径，必须一个人扛到底；固件能在核心板裸板上先跑，不必等板。

---

## 0. 为什么不能简单"一人一半"

赛题的评分点是**串联**的：PCB 不打 → 焊不了 → 固件没板跑 → 五项测不了。所以分工的第一原则是**保证关键路径不空转**，第二原则才是工作量平均。

| 工作 | 能否并行 | 依赖 |
|---|---|---|
| PCB 板框/布线/下单 | ❌ 单线程 | 原理图冻结 |
| 固件五项功能 | ✅ 可在核心板裸板跑 | 只要引脚定死 |
| 机械 CAD / 3D 打印 | ✅ 独立 | 只有尺寸依赖赛题（Ø160×46、视窗 22.5°） |
| 采购 / 焊接 | 🟡 半并行 | BOM 冻结 → 等快递 |

所以：**A 扛 PCB/电源/焊接，B 扛固件/机械**，是唯一能在等板期不空转的切法。

## 2. 分工表（按阶段，直接照着做）

### 阶段 0：打板前（现在 → 下单）

| # | A 做 | B 做 | 交接点 |
|---|---|---|---|
| 1 | 导入板框/孔（`PCB_P0_PLAYBOOK.md` §2），核对 6 项 | 用 CubeMX 建工程，先把 PA6/PA7/PB0 配成 **TIM3 三路开漏 PWM** | 引脚表冻结（§3 表 2） |
| 2 | 决定 U3 封装（SOT-223 自购 / 改 TO-220 用提供件） | 核心板裸板点灯：PB2 板载 LED 闪 | — |
| 3 | 改 KEY 封装为 C5379898（5.8×5.8 六脚） | 串口指令框架（USART2 + 命令解析） | 协议表（§3 表 3） |
| 4 | 布线规则落地：手工布 6 条关键路径 → 自动布线 → DRC 0 | PA1 输入捕获 + EXTI 中断，LED 亮 1 s | 中断优先级/去抖参数 |
| 5 | Gerber/钻孔/BOM/坐标导出，下单 | 机械 CAD 第一版：鼓、视窗、底座、联轴器 | 孔位坐标（§1.2 of PLAYBOOK） |

**阶段 0 的完成判据**：板子下单 + 裸板上「三路 PWM 会调光 + 串口能收发 + 中断能点灯」全通过。

### 阶段 1：等板期（3–7 天）

| A | B |
|---|---|
| 按 BOM 采购（已带立创编号），买双份易损件 | 五项功能在**裸板**上全跑通（电机用示波器看 PWM，不接电机） |
| 准备焊接：烙铁/热风/助焊剂/镊子/吸锡带/放大镜 | 上位机小工具（串口发 `RGB r,g,b`、`SET 1200`） |
| 写"上电检查表"（限流 100 mA 起、逐路测压） | 打印机械件，试装鼓与联轴器 |

### 阶段 2：板到（D+1 ~ D+3）

| 顺序 | 谁 | 动作 | 通过判据 |
|---|---|---|---|
| 1 | A | 目检 + 万用表测 VIN-5V-3V3-GND 之间**无短路** | 电阻 > 1 kΩ |
| 2 | A | 限流 100 mA 上电，测 5V/3.3V | 5.0±0.2 V、3.3±0.1 V |
| 3 | A | 摸 U3 温度、加载 RGB 全亮 10 min | 壳温 < 70 °C |
| 4 | B | 插核心板，下载"最小系统"程序 | PB2 闪灯 |
| 5 | B | 逐项联调五项功能 | 每项有现象、有记录 |
| 6 | 共同 | 预演演示顺序 2 遍 | 5 分钟内跑完五项 |

### 阶段 3：第一阶段验收（当天 8:30 提交，测试 ≤10 min）

- **B 操作**（按键/串口/示波器），**A 讲解**（电源树、驱动原理、测试点位置）。
- 演示顺序固定：① 最小系统 → ② RGB 三路常亮 + 4 级调光 → ③ 遮挡红外看信号变化 → ④ EXTI 点亮 LED 1 s → ⑤ 电机启停/调速。
- 风险预案：红外③最容易受环境光干扰 → 提前把教室灯全开/关各试一次；串口⑤卡住就切按键演示。

### 阶段 4：第二阶段（机械 + 联调）

| A | B |
|---|---|
| 鼓/视窗/底座装配，联轴器对中，动平衡 | 索引闭环（TIM2 捕获 + 转速环）、扫描时序、帧缓存 |
| 防护罩、消光处理、线束固定 | 图像/动画、失锁保护、切图 |
| 电机电流/温升、长时间运行可靠性 | 30 fps / 1800 rpm 加分项、PC 传图 |

> 联调期的规矩：**A 只负责"机械侧现象"（抖动、偏心、噪声），B 只负责"时序侧现象"（斜纹、错行、丢帧）**，每 30 分钟交换一次视角。两人同时改同一现象 = 谁都改不好。

## 3. 三张必须写死的接口表（分工的前提）

### 表 1：电源树与上电顺序

```
7.4~12V (J1) ─ D1(SS34) ─┬─ U3(LM1117-ADJ) 5V ─ JP1 ─ 核心板 PIN_IN_+5V(排针40脚) ─ 核心板LDO ─ 3.3V
                          ├─ U2(LM1117-3.3) 3.3V ─ 红外/指示/J7-4(经R23,默认不贴)
                          └─ J6 电机 VIN（独立支路）
GND：单点汇接在 J1 的 GND 引脚下方
```
上电顺序：**先测压、再插核心板、最后接电机**。

### 表 2：引脚冻结表（来源：核心板原理图第 7 页实测）

| 功能 | 引脚 | 复用 | 配置要点 |
|---|---|---|---|
| RGB 红/绿/蓝 | PA6 / PA7 / PB0 | TIM3_CH1/2/3 | **开漏输出**，占空比反相（0% = 最亮） |
| 电机 PWM | PB6 | TIM4_CH1 | 3.3V 输出，见 RISKS R2 |
| 红外索引 | PA1 | TIM2_CH2 | 输入捕获 + EXTI 双边沿 |
| 串口 | PA2(TX) / PA3(RX) | USART2 | 115200 8N1 |
| 按键 | PC0 / PC1 | GPIO 输入 | 内部上拉，20 ms 消抖 |
| 板载 LED | PB2 | GPIO 输出 | 高电平点亮。PB2 就是 BOOT1：复位瞬间必须为低才从 Flash 启动（板上有 10 kΩ 下拉，正常；**别在复位电路上做文章**） |

### 表 3：串口协议（第一阶段够用，第二阶段可扩展）

| 指令 | 回复 | 说明 |
|---|---|---|
| `PING` | `OK PONG` | 链路自检 |
| `RGB r,g,b` | `OK RGB r,g,b` | 0–100 百分比，内部转反相占空比 |
| `BRIGHT n` | `OK BRIGHT n` | 0–3 四档（验收要求 ≥4 级） |
| `START` / `STOP` | `OK START` | 电机启停 |
| `SET n` | `OK SET n` | 目标转速 rpm（第二阶段闭环用） |
| `STAT` | `OK rpm=... ir=...` | 调试用 |

格式：ASCII 文本，`\n` 结尾，大小写不敏感；错误回 `ERR <原因>`。

## 4. 时间线（按 4 周倒排，验收日已知就对着改）

| 周 | A（硬件） | B（软件/机械） | 周末应达到 |
|---|---|---|---|
| W1（10/26–11/1） | 板框+孔落地、封装修正、布线 80% | 固件骨架 + 裸板前 3 项、机械粗模 | 板能发出去；裸板能点灯调光 |
| W2（11/2–11/8） | 布线收尾、DRC、Gerber、**下单**、采购 | 五项全通（裸板）、机械件打印 | **板已下单**；五项有波形/现象 |
| W3（11/9–11/15） | 等板/收货/焊接/上电/测压 | 上位机工具、装配预演 | 板上电正常，核心板能跑 |
| W4（11/16–11/22） | 修板、可靠性、测点 | 联调五项、预演 | **第一阶段验收** |
| W5–W7 | 机械装配、动平衡、防护 | 闭环、扫描、成像、失锁 | 第二阶段验收 |

> 关键节点只有两个：**W2 周末必须下单**（否则后面全顺延）、**W4 之前五项必须全通**。

## 6. 协作机制（比分工本身更重要）

1. **每天 5 分钟站会**：昨天完成 / 今天要做 / 卡在哪。卡 2 小时就换人看，别硬扛。
2. **单一信息源 = 这个仓库**。原理图改动 → 改的人在 EDA 里重跑网表 → 更新 `docs/CHANGELOG.md` → 口头通知对方。
3. **接口先行**：§3 三张表任一改动，必须先说再改。
4. **不留单点**：上电流程、烧录、五项演示，两个人都要独立做过一遍（验收当天可能只有一个人在）。
5. **器件保护**：赛题写明"元件损坏可再申请，但影响评分" → 限流上电、防反接、电机单独供电，这三条是评分的一部分。
6. **每周一次"盲测"**：一人操作、一人当评委按 §5 表格打分，暴露演示话术问题。

## 7. 如果两人水平结构不同，换这两种切法

| 方案 | 切法 | 适合 | 风险 |
|---|---|---|---|
| **A（推荐）** | 硬件 / 软件+机械 | 一人偏硬、一人偏软 | PCB 全压在 A 身上，A 生病就停摆 |
| B | 一人管电源+电机+机械装配；一人管 RGB+红外+固件 | 两人都会写代码 | 电源/电机与固件耦合紧，接口要先定死 |
| C | 一人对外（采购/文档/演示），一人对内（PCB+固件） | 不推荐 | 关键路径集中在一个人，且"对外"的人学不到东西 |

## 8. 从两份 PDF 里读出来的 3 个"现在就得改"

| # | 发现 | 影响 | 谁改 |
|---|---|---|---|
| 1 | 赛题表 1 提供的**无锁按键是 C5379898（5.8×5.8 六脚 DPDT 插件）**，不是 6×6 四脚贴片 | 若 PCB 按 6×6 画，提供的按键插不上，得自购（还影响评分） | A |
| 2 | 赛题表 1 提供的**可调 LDO 是 TO-220（C498319）**，本板 U3 是 SOT-223 | 用不了提供件；且 SOT-223 散热更差（1.2 W → ΔT 100 °C+） | A（打板前定） |
| 3 | 赛题图 3 把 RGB 灯珠标成**共阳**，而 TASKS 记的是共阴 | 极性反了三路全灭；好在 Q1–Q3 低边方案正好是共阳备份，**别从 BOM 删** | A + B（拿到实物先测） |

> 另外两条已核对无误：**排针 40 脚 = PIN_IN_+5V、38 脚 = +3V3**（核心板原理图第 7 页），TASKS 的纠正是对的；**PA6/PA7/PB0/PB6/PA1/PA2/PA3 的位置**也与 `docs/refs/引脚分配.md` 一致（但该文档里 P2 的编号整体偏 2 个脚，以原理图为准）。
