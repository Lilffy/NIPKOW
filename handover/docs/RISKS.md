## 4. 三条"现在改一个电阻 vs 打板后飞线"的决策

这三条如果拖到板子回来才发现，每条都要飞线 + 割铜：

1. **R1 的非 FT 引脚**：现在把 10k 改接 +3V3，零成本；打板后要割线飞线。
2. **R2 的电机 PWM 电平**：现在在 J6-3 旁预留 1k + 4.7k + SOT-23（2N7002）三个焊盘，零成本；打板后要立着焊。
3. **R3 的 JP1/USB**：现在丝印加一行字，零成本；打板后只能靠记性。

> 建议把这三条做成 PCB 上的**可选焊盘**（默认不贴），比在文档里写"注意"有用得多。
