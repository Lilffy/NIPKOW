# 固件工程（STM32F407VET6 / 天空星核心板）

> 负责人：B。开发环境建议 **STM32CubeIDE**（或 Keil MDK + HAL）。
> 引脚定义已冻结，见 `docs/SCHEMATIC_LAYOUT.md`。

## 里程碑

| 编号 | 内容 | 验收 | 状态 |
|---|---|---|---|
| M0 | 骨架：168 MHz、SysTick、USART2 115200、PB2 心跳灯 | 串口打印版本号 + LED 1 Hz | ⬜ |
| M1 | 红外 EXTI：PA1 下降沿、消抖、LEB、LED 亮 1 s（非阻塞） | 遮光/移开各触发一次 | ⬜ |
| M2 | RGB PWM：TIM3 CH1/2/3（PA6/PA7/PB0），开漏+反相，≥4 级 | 8 色可辨 | ⬜ |
| M3 | 电机：TIM4_CH1（PB6）启停/调速 | 电机可转可停可调速 | ⬜ |
| M4 | 串口协议：`START` / `STOP` / `SET <rpm>` / `RGB r g b` | 串口助手可控 | ⬜ |
| M5 | 稳速闭环：索引周期测量 + PI，1200±20 rpm | 30 s 稳定 | ⬜ |
| M6 | 整帧成像：16×25 帧缓冲、125 µs 像素、切图、动画、失锁 | 静态图 30 s 不漂移 | ⬜ |
| M7 | 加分：灰度、30 fps、PC 传图 | 按赛题 | ⬜ |

## 烧录

- ST-Link 接核心板 SWD（PA13/PA14 + GND + 3V3）
- 串口：J7（GND / TX=PA2 / RX=PA3），115200 8N1
- 上电顺序：先测 3.3V/5V 正常，再插核心板

## 关键约束（务必遵守）

1. RGB 三路必须 **GPIO 开漏输出**，PWM 占空比**取反**（低电平点亮），否则灯关不死
2. 索引 PA1：遮光时高、透光时低 → **下降沿**触发
3. 中断里只置标志/记时间戳，1 秒 LED 用 SysTick 非阻塞
4. 切帧只能在索引中断里做，避免撕裂
5. 失锁判据：索引间隔 > 1.5T 立即熄灯并复位状态机
